# Slice 7(eval 包)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or executing-plans. Checkbox (`- [ ]`) tracking.

**Goal:** 建 `@agentforge/eval` 包:Task/Runner/Metrics + 2-3 示例 task + head-to-head + CLI。

**Architecture:** Runner 跑 `AgentForgeHarness.prompt(task.prompt)` → 从 `harness.agent.state.messages` 最后 AssistantMessage 提取 reply/usage(`usage.input`/`usage.output`/`usage.cost.total`)→ acceptanceChecks(声明式)→ 聚合 metrics(completion rate/cost/wall-clock;pass@3 可选)。drop retries(pi 不暴露)。spec: `docs/superpowers/specs/2026-06-25-slice7-eval-design.md`(v2,red-team 全吸收)。

**Tech Stack:** TypeScript / pnpm monorepo / vitest / `@agentforge/harness`(AgentForgeHarness)/ `@agentforge/cli`(env-config getApiKey)/ `@earendil-works/pi-ai`(getModel)/ `@earendil-works/pi-agent-core`(AgentMessage/AssistantMessage)。
